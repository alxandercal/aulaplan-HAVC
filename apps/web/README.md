# AulaPlan frontend (Nuxt 4)

Este workspace no es un starter aislado: forma parte del monorepo y requiere la API Python y los emuladores Auth/Firestore.

**Guía:** [`../../docs/INSTALACION.md`](../../docs/INSTALACION.md). Ejecuta `npm install` desde la raíz y luego `npm run dev:web`.

**Variables:** ver `apps/web/.env.example`. Nunca agregues secretos Admin SDK ni claves de IA a `NUXT_PUBLIC_*`.
